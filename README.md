# 口头禅猎手 (Catchphrase Guard)

专为个人自用打造的安卓后台口头禅实时监听与推送提醒工具（适配 Android 17 / vivo OriginOS）。

## 核心特性
- **100% 纯本地离线识别**：内置 `sherpa-onnx` 中文流式语音识别模型（Int8 量化），断网可用、零延迟、零云端上传。
- **默认盯防词库**：预置 `没有`、`不是`，支持在 App 内随时动态添加、暂停或删除任意中文口头禅。
- **实时横幅推送 + 三连震动**：检测到口头禅约 0.3～0.6 秒内立即弹出高优先级系统通知，并记录当时语境片段与今日统计。
- **云端零环境自动打包**：每次推送代码到 GitHub，`GitHub Actions` 自动构建签名版 `.apk` 并发布到仓库的 **Releases** 页面，手机浏览器点开即可直接下载安装。

## 如何获取 APK 安装包
1. 将本仓库推送到你的 GitHub（公开或私有仓库均可）。
2. 打开 GitHub 仓库顶部的 **Actions** 标签页，等待 `Build Android APK` 变成绿色对勾（首次约 3～4 分钟）。
3. 打开仓库右侧的 **Releases** 页面，手机直接点击 `CatchphraseGuard-v1.0.x.apk` 下载安装。
