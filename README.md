# 口头禅猎手 v2.0 (Catchphrase Guard)

专为个人自用打造的安卓后台口头禅实时监听与本人声纹识别工具（深度适配 Android 17 / vivo OriginOS）。

## v2.0 核心特性
- **本人声纹专属过滤（3D-Speaker CAMP++）**：内置阿里达摩院开源中文声纹模型，10 秒三步引导采集多距离个人声纹。只有你本人的声音才会触发推送与震动，旁人/视频声音自动静默拦截并记录相似度。
- **OriginOS 现代原生质感 UI**：底部三栏架构（监听主控台 / 声纹与词库 / 统计与设置）、动态声波呼吸环、实时声纹试音沙盒，支持深浅色模式自动切换。
- **100% 纯本地离线识别**：全部语音转写与声纹计算均在手机本地完成，断网可用、零延迟、零云端上传。
- **云端零环境自动打包**：推送代码到 GitHub 后，GitHub Actions 自动构建签名版 `.apk` 并发布到 **Releases**，支持直接覆盖升级安装。
