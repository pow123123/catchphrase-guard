# 口头禅猎手 v5.0 (Catchphrase Guard)

专为个人自用打造的离线口头禅监听与习惯改善助手（适配 Android 8–17 / vivo OriginOS）。

## v5.0 核心特性
- **系统级入口，高频操作不进 App**：支持下拉控制中心快捷开关（Quick Settings Tile）、常驻通知栏实时计时与「暂停 15 分钟 / 继续 / 结束」，单条提醒通知上可直接点「不是我」或「暂停 15 分钟」。
- **「不是我」即时纠偏 + 负样本学习**：误报时在通知或结束小结点击「不是我」，不仅撤销计数，还会记住他人声纹特征（最多 20 条），下次类似声音自动过滤；漏报被过滤时也可在小结中点「其实是我」补充本人声纹。
- **按次监听与习惯趋势**：支持「直到我结束 / 30 分钟 / 1 小时 / 2 小时」时长；每次结束提供小结（次数、每小时频率、与上次对比、逐条回顾）；「趋势」页展示 7/30 天每小时频率柱状图、自定义目标线、连续达标天数及各词每周变化。
- **零念稿本人声纹 + 100% 本地离线**：内置 Sherpa-ONNX 离线中文 ASR 与 3D-Speaker CAMP++ 声纹模型，全部录音与计算均在手机本地完成，不保存、不上传音频。
- **干净克制的原生 Material 3**：双底栏（「今天」/「趋势」）+ 右上角设置；跟随系统深浅色与动态取色，无装饰性常驻动画。
- **云端零环境自动打包**：推送代码到 GitHub 后，GitHub Actions 自动构建签名版 `.apk` 并发布到 **Releases**，支持直接覆盖升级安装。
